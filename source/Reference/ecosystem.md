# Ecosystem

{audience}`beginners, all`

Tango Controls offers a rich ecosystem for developers and clients alike.
The ecosystem is best appreciated via these maps which show what exists and where it is situated in the software stack. Use the [map key](#map-key) to understand the colour code used.

Since Tango is a developer's toolkit there are many libraries and tools for existing devices and clients. Refer to the [developers guide map](#developers-overview) for a quick overview.

Tango is designed to run small and large systems. To support managing large installations a number of administration tools are provided. Refer to the [administrators map](#administrators-overview) for a quick overview.

All control systems need to be able to archive data so they one can look at past data when needed to. Tango comes with a number of archiving solutions. Refer to the [archiving map](#archiving-overview) for a quick overview.

In addition to the rich Python, C++ and Java APIs for Tango a number of other languages and tools can be used together with Tango. Refer to the [bindings map](#bindings-overview) for a quick overview of the known bindings.
